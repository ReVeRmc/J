# 🎉 J AI Assistant - Финальная версия

Серверный AI-ассистент на **PowerShell** (`server.ps1`) с HTTP API.
Клиентские файлы временно удалены — взаимодействие идёт напрямую через API
(POST `http://localhost:8080/` с телом `{"message":"..."}`).

## 🚀 Быстрый старт

### Требования

- Windows / macOS / Linux / Android (Termux) с PowerShell 5.0+ или pwsh 7+
  (используется `System.Net.HttpListener`)

### Запуск сервера

```powershell
.\start-server.bat        # при запуске автоматически запрашивает права администратора
```

или напрямую:

```powershell
# Windows (от имени администратора):
powershell -ExecutionPolicy Bypass -File .\server.ps1

# macOS / Linux / Android (Termux + PowerShell 7):
pwsh -ExecutionPolicy Bypass -File ./server.ps1
```

Сервер по умолчанию слушает `http://localhost:8080`.

### Отправка запросов (API)

```powershell
# GET — проверка доступности сервера: вернёт {"response":"pong"}
curl http://localhost:8080/

# POST — сообщение ассистенту:
curl -X POST http://localhost:8080/ -H "Content-Type: application/json" -d '{\"message\":\"помощь\"}'
```

### Параметры сервера

```powershell
.\server.ps1 -Port 9000 -ServerHost localhost
```

## 🛠️ Возможности (версия 3.0)

### 💬 Активный диалог
Приветствия, время/дата, благодарность, прощание, база знаний (Python,
JavaScript, AI, ML, нейросети), контекст беседы и история реплик на сервере.
Напишите «помощь» — ассистент покажет полный список команд.

### 📂 Работа с файлами и папками
```
покажи список файлов [папка]
покажи файл example.txt            # чтение кода/текста, файл становится «активным»
создай файл "test.txt" текст: "Привет!"
добавь в файл "test.txt" "новая строка"
замени "старое" на "новое"         # в активном файле (диалог о коде)
удали файл "test.txt"
создай папку "new"
перемести "a.txt" в "b.txt"
скопируй "a.txt" в "b.txt"
найди "report"                      # рекурсивный поиск по имени
отмени                              # откат последнего изменения файла
```
Доступны все пути в файловой системе (для системных папок запускайте сервер от
имени администратора). Работает на Windows; на macOS/Linux/Android (Termux +
PowerShell 7) команды выполняются через `/bin/sh`.

### 🖥️ Программы и команды
```
выполни ipconfig /all               # выполнение команд с выводом и кодом возврата
запусти notepad                     # открытие программ
открой calc.exe
```
Ограничений по командам нет — ассистент выполняет любые команды системы
(используйте осознанно; все запуски логируются, «отмени» помогает с файлами).

### 📊 Мониторинг системы
```
статус системы                      # ОС, CPU, RAM, диск, топ процессов
какие процессы запущены
```

## 📝 Логирование

Все события пишутся автоматически в папку `logs/` (создаётся при запуске):

| Файл | Содержание |
|---|---|
| `logs/dialog.jsonl` | Полный лог активного диалога: каждая реплика (timestamp, номер хода, роль, распознанное намерение, текст) в формате JSON Lines |
| `logs/actions.log` | Журнал всех действий с файлами, папками, программами и командами (LIST_DIR, READ_FILE, CREATE_FILE, REPLACE_IN_FILE, RUN_CMD, DELETE, UNDO_RESTORE, BLOCKED_CMD и т.д.) |
| консоль сервера | Live-лог операций с цветовыми уровнями INFO/SUCCESS/WARNING/ERROR |

В ответах API вместе с текстом возвращается распознанное намерение
(поле `intent`), что удобно для проверки понимания запросов.

## 🔧 Решение проблем

### Сервер не отвечает
1. Убедитесь, что `server.ps1` запущен и не завершился с ошибкой.
2. Проверьте доступность: `curl http://localhost:8080/` — должен вернуть `pong`.
3. Проверьте, что порт 8080 не занят: `netstat -ano | findstr :8080`.

### Ошибка «Access is denied» при запуске сервера
HttpListener требует прав на привязку адреса. Запустите PowerShell от имени
администратора или используйте `localhost` (по умолчанию).
