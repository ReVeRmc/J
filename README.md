## 📦 Система автообновления

### Создание архива обновления

**Способ 1: PowerShell скрипт**
```powershell
.\create-archive.ps1
```

**Способ 2: BAT файл**
```cmd
create-archive.bat
```

**Способ 3: Голосовая команда**
```
упакуй в архив
создай архив обновления
```

**Что делает скрипт:**
- 📋 Копирует все важные файлы проекта
- 🗑️ Исключает node_modules, dist, release, logs
- 📦 Создаёт ZIP-архив в папке `updates/`
- 🏷️ Называет архив: `j-ai-assistant-v{версия}.zip`

### Как обновить приложение

1. **Создайте архив на исходном ПК:**
   ```powershell
   .\create-archive.ps1
   ```

2. **Перенесите архив на целевой ПК:**
   - USB флешка, облако, сеть

3. **Поместите архив в папку `updates/`**

4. **Запустите `Update.ps1`**

5. **Скрипт автоматически:**
   - Создаст резервную копию
   - Распакует обновление
   - Применит новые файлы
   - Пересоберёт проект

### Откат обновления

Если обновление вызвало проблемы:

```powershell
.\Rollback.ps1
```

Скрипт найдёт последнюю резервную копию и восстановит проект.

## 🔧 Решение проблем

### Приложение не запускается
1. Проверьте логи: `install.log`
2. Запустите от имени администратора
3. Проверьте антивирус

### Обновление не работает
1. Проверьте формат ZIP-архива
2. Убедитесь что все файлы в корне архива
3. Проверьте права доступа к папке `updates/`

### Откат не работает
1. Проверьте наличие папки `backup_*`
2. Запустите `Rollback.ps1` от имени администратора
