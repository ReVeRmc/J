# 📦 Создание архива обновления J AI Assistant

## 🎯 Назначение

Скрипт `create-archive.ps1` создаёт ZIP-архив проекта для удобного переноса и обновления на других компьютерах.

---

## 🚀 Как использовать

### Способ 1: PowerShell скрипт
```powershell
.\create-archive.ps1
```

### Способ 2: BAT файл
```cmd
create-archive.bat
```

### Способ 3: Голосовая/текстовая команда
```
упакуй в архив
создай архив обновления
```

---

## 📋 Что включается в архив

### ✅ Включается:
- `package.json` - конфигурация проекта
- `package-lock.json` -锁定 зависимости
- `tsconfig.json` - настройки TypeScript
- `vite.config.ts` - настройки Vite
- `electron-builder.yml` - настройки сборки
- `index.html` - главный HTML файл
- `src/` - исходный код (React компоненты, утилиты)
- `electron/` - Electron backend
- `build/` - ресурсы сборки (иконки)
- `*.ps1` - PowerShell скрипты
- `*.cjs` - вспомогательные скрипты
- `*.md` - документация

### ❌ Исключается:
- `node_modules/` - зависимости (устанавливаются через npm install)
- `dist/` - собранная версия (создаётся через npm run build)
- `release/` - готовые .exe файлы
- `updates/` - папка обновлений
- `backup_*/` - резервные копии
- `*.log` - логи
- `temp_archive/` - временные файлы
- `.git/` - Git репозиторий
- `.vscode/` - настройки VS Code
- `*.tmp` - временные файлы

## 🔄 Как обновить приложение на другом ПК

### Шаг 1: Создание архива на исходном ПК
```powershell
.\create-archive.ps1
```

Архив будет создан в папке `updates/j-ai-assistant-v{версия}.zip`

### Шаг 2: Перенос архива
Скопируйте архив на целевой ПК любым способом:
- USB флешка
- Облачное хранилище
- Сетевая папка
- Email

### Шаг 3: Применение обновления на целевом ПК
```powershell
# Поместите архив в папку updates/
# Затем запустите:
.\Update.ps1
```

Скрипт автоматически:
- Создаст резервную копию текущей версии
- Распакует архив
- Применит новые файлы
- Пересоберёт проект
- Очистит временные файлы

- ✅ Исключаются все временные и системные файлы
- ✅ Проверяется наличие необходимых файлов перед упаковкой
- ✅ Создаётся резервная копия перед применением обновления

### Рекомендации:
- 🔒 Проверяйте целостность архива перед переносом
- 🔒 Используйте защищённые каналы передачи
- 🔒 Создавайте резервные копии перед обновлением
- 🔒 Проверяйте версию перед применением

## 🔧 Настройка

### Изменение версии
Отредактируйте `package.json`:
```json
{
  "version": "2.3.0"
}
```

### Добавление файлов в архив
Отредактируйте `create-archive.ps1`, массив `$includeItems`:
```powershell
$includeItems = @(
    "package.json",
    "src",
    "electron",
    # Добавьте новые файлы/папки здесь
    "my-custom-folder"
)
```

### Исключение дополнительных файлов
Отредактируйте `create-archive.ps1`, массив `$excludePatterns`:
```powershell
$excludePatterns = @(
    "node_modules",
    "dist",
    # Добавьте новые паттерны здесь
    "*.custom"
)
```

## 💡 Примеры использования

### Пример 1: Создание архива для переноса
```powershell
# На исходном ПК:
.\create-archive.ps1

# Скопируйте updates/j-ai-assistant-v2.2.0.zip на USB

# На целевом ПК:
# Поместите архив в updates/
.\Update.ps1
```

### Пример 2: Резервное копирование
```powershell
# Создайте архив текущей версии
.\create-archive.ps1

# Скопируйте архив в безопасное место
Copy-Item updates\j-ai-assistant-v2.2.0.zip D:\Backups\
```

### Пример 3: Откат к предыдущей версии
```powershell
# Если обновление вызвало проблемы:
.\Rollback.ps1

# Или восстановите из архива:
# 1. Распакуйте архив в отдельную папку
# 2. Скопируйте файлы обратно в проект
# 3. Запустите npm install && npm run build
```

## 📈 Статистика

**Размер архива:**
- Без node_modules: ~5-10 MB
- С node_modules: ~200-500 MB (не рекомендуется)

**Время создания:**
- Обычно: 5-15 секунд
- Зависит от размера проекта и скорости диска

**Время обновления:**
- Распаковка: 5-10 секунд
- npm install: 30-60 секунд
- npm run build: 10-20 секунд
- **Всего: ~1-2 минуты**
