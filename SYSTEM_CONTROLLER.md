# 🎮 Система управления ПК (по аналогии с Laitis)

## 📋 Обзор

J AI Assistant теперь может управлять вашим компьютером с помощью голосовых и текстовых команд, как голосовой ассистент Laitis.

## 🔧 Техническая реализация

### Архитектура

```
┌─────────────────────────────────────┐
│      Пользовательская команда       │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   smartResponder.ts                 │
│   ├─ Проверка системных команд      │
│   └─ Вызов systemController         │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   systemController.ts               │
│   ├─ Поиск команды по триггерам     │
│   ├─ Выполнение действия            │
│   └─ Возврат результата             │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Electron main.js                  │
│   └─ Выполнение системной команды   │
└─────────────────────────────────────┘
```

### Основные файлы

- **`src/utils/systemController.ts`** - контроллер системных команд
- **`src/utils/smartResponder.ts`** - интеграция с обработчиком
- **`src/App.tsx`** - UI кнопки управления
- **`electron/main.js`** - выполнение системных команд

### Категории команд

```typescript
export const COMMAND_CATEGORIES = {
  APP: 'app',           // Запуск приложений
  SYSTEM: 'system',     // Системные команды
  MEDIA: 'media',       // Управление медиа
  BROWSER: 'browser',   // Управление браузером
  WINDOW: 'window',     // Управление окнами
  FILE: 'file',         // Работа с файлами
  SCREENSHOT: 'screenshot', // Скриншоты
};
```

## 🚀 Расширение функционала

### Добавление новых команд

1. Откройте `src/utils/systemController.ts`
2. Добавьте новую команду в массив `SYSTEM_COMMANDS`:

```typescript
{
  id: 'unique_id',
  name: 'Название команды',
  category: COMMAND_CATEGORIES.APP,
  triggers: ['триггер1', 'триггер2'],
  action: async () => {
    // Выполнение команды
    return '✅ Результат';
  },
  description: 'Описание команды',
}
```

3. Пересоберите приложение

### Пример: Добавление команды открытия VS Code

```typescript
{
  id: 'open_vscode',
  name: 'Открыть VS Code',
  category: COMMAND_CATEGORIES.APP,
  triggers: ['открой vs code', 'открой визуал студио', 'открой редактор кода'],
  action: async () => {
    if (window.electronAPI?.system.exec) {
      await window.electronAPI.system.exec('start code');
      return '✅ VS Code открыт';
    }
    return '❌ Команда недоступна в веб-версии';
  },
  description: 'Открывает Visual Studio Code',
}
```
