### 3. Добавлена система фактов

```typescript
const FUN_FACTS = [
  'Знаете, что искусственные нейронные сети вдохновлены биологическим мозгом?...',
  'Первый компьютерный баг был настоящим жуком!...',
  'Python назван в честь комедийного шоу "Monty Python\'s Flying Circus"...',
  // ... ещё 17 фактов
];

let lastFactIndex = -1;

function getNextFact(): string {
  let index: number;
  do {
    index = Math.floor(Math.random() * FUN_FACTS.length);
  } while (index === lastFactIndex && FUN_FACTS.length > 1);
  lastFactIndex = index;
  return FUN_FACTS[index];
}
```

**Преимущества:**
- 20 интересных фактов
- Не повторяет последний факт
- Работает с командой "ещё"

---

### 4. Исправлена логика проверки базы знаний

#### Было:
```typescript
const keywords = key.split('_');
if (keywords.some(kw => lower.includes(kw))) {
  return { ...response, source: 'local' };
}
```

#### Стало:
```typescript
const keywords = key.split('_');
// Проверяем все слова ключа
if (keywords.every(kw => kw.length < 3 || lower.includes(kw))) {
  return { ...response, source: 'local' };
}
// Или хотя бы одно значимое слово
if (keywords.some(kw => kw.length >= 3 && lower.includes(kw))) {
  return { ...response, source: 'local' };
}
```

**Улучшения:**
- Более точное совпадение
- Игнорирует короткие слова (< 3 символов)
- Проверяет все слова или хотя бы одно значимое
