# 🖥️💻 СЕРВЕРНО-КЛИЕНТСКАЯ АРХИТЕКТУРА J AI ASSISTANT

## 🎯 Обзор

J AI Assistant разделён на две части:
- **Сервер** (`server.ps1`) - AI логика, обработка запросов
- **Клиент** (`client.html`) - простой чат с кнопкой голоса

---

## 📦 Компоненты

### Серверная часть

**Файлы:**
- `server.ps1` - основной серверный скрипт
- `start-server.bat` - BAT обёртка для запуска

**Что делает:**
- ✅ Слушает HTTP запросы на `http://localhost:8080`
- ✅ Обрабатывает текстовые запросы
- ✅ Возвращает ответы через AI логику
- ✅ Ведёт историю диалога
- ✅ Управляет контекстом разговора
- ✅ Логирует все операции

**Запуск:**
```powershell
.\server.ps1
```

Или:
```cmd
start-server.bat
```

---

### Клиентская часть

**Файлы:**
- `client.html` - клиентский интерфейс
- `start-client.ps1` - скрипт запуска
- `start-client.bat` - BAT обёртка

**Что делает:**
- ✅ Простой чат-интерфейс
- ✅ Кнопка голосового ввода (🎤)
- ✅ Отправка запросов на сервер
- ✅ Отображение ответов
- ✅ Индикатор подключения
- ✅ Минималистичный дизайн

**Запуск:**
```powershell
.\start-client.ps1
```

Или:
```cmd
start-client.bat
```

---

## 🔄 Как это работает

### Архитектура

```
┌─────────────────┐
│   Клиент        │
│   (browser)     │
│                 │
│  🎤 Голос       │
│  💬 Чат         │
└────────┬────────┘
         │
         │ HTTP POST
         │ { message: "..." }
         │
         ▼
┌─────────────────┐
│   Сервер        │
│   (PowerShell)  │
│                 │
│  🧠 AI логика   │
│  📚 База знаний │
│  🔄 Контекст    │
└────────┬────────┘
         │
         │ HTTP Response
         │ { response: "..." }
         │
         ▼
┌─────────────────┐
│   Клиент        │
│   (browser)     │
│                 │
│  💬 Ответ       │
└─────────────────┘
```

### Процесс

1. **Пользователь** вводит текст или нажимает кнопку голоса
2. **Клиент** отправляет POST запрос на `http://localhost:8080`
3. **Сервер** получает запрос, обрабатывает через AI логику
4. **Сервер** возвращает JSON ответ
5. **Клиент** отображает ответ в чате

## 🚀 Быстрый старт

### Шаг 1: Запуск сервера

Откройте PowerShell и выполните:
```powershell
.\server.ps1
```

Вы увидите:
```
============================================
   J AI Assistant - Серверная часть
   Версия 2.3
============================================

[2024-01-15 14:30:00] [SUCCESS] Запуск сервера J AI Assistant...
[2024-01-15 14:30:00] [SUCCESS] Сервер доступен на http://localhost:8080
[2024-01-15 14:30:00] [WARNING] Нажмите Ctrl+C для остановки

[2024-01-15 14:30:00] [SUCCESS] Сервер запущен и ожидает подключений...
```

**Оставьте это окно открытым!**

### Шаг 2: Запуск клиента

Откройте **второе** окно PowerShell и выполните:
```powershell
.\start-client.ps1
```

Или просто дважды кликните на `start-client.bat`.

Клиент откроется в браузере по умолчанию.

### Шаг 3: Общение

В клиенте:
- Введите текст в поле ввода и нажмите Enter
- Или нажмите кнопку 🎤 и скажите что-нибудь
- Сервер обработает запрос и вернёт ответ

## 🔐 Безопасность

### Локальная сеть:
- Сервер слушает только на `localhost`
- Доступ только с локального компьютера
- Нет внешних подключений

### Ограничения:
- Нет аутентификации (локальное использование)
- Нет шифрования (HTTP, не HTTPS)
- Нет защиты от XSS (локальный клиент)

**Рекомендации:**
- Используйте только в локальной сети
- Не открывайте порт наружу
- Не используйте в публичных сетях

## 🐛 Решение проблем

### Сервер не запускается

**Проблема:** "Отказано в доступе"

**Решение:**
```powershell
# Запустите от имени администратора
# Или измените порт на > 1024
.\server.ps1 -Port 9000
```

### Клиент не подключается

**Проблема:** "❌ Сервер недоступен"

**Решение:**
1. Убедитесь что сервер запущен
2. Проверьте порт (должен быть 8080)
3. Проверьте firewall

### Голос не работает

**Проблема:** Кнопка 🎤 не появляется

**Решение:**
- Используйте Chrome или Edge
- Разрешите доступ к микрофону
- Проверьте настройки браузера
