# 🧠 Активный диалог с распознаванием контекста

## 🎯 Что добавлено

### Контекстный движок (Context Engine)

Продвинутая система понимания контекста диалога, которая позволяет J:

1. **Распознавать намерения** — 25+ типов намерений пользователя
2. **Извлекать сущности** — темы, города, языки, выражения
3. **Помнить контекст** — текущая тема, предыдущие темы, сущности
4. **Анализировать настроение** — позитивное, негативное, нейтральное
5. **Поддерживать follow-up** — продолжение темы, уточнения
6. **Генерировать осмысленные ответы** — на основе контекста

---

## 🔄 Как это работает

### 1. Анализ намерения

Каждый запрос анализируется через систему паттернов:

```typescript
// Примеры намерений:
- question_about_self    → "Кто ты?", "Расскажи о себе"
- search_info           → "Найди информацию о...", "Что такое..."
- weather               → "Какая погода в..."
- translate             → "Переведи на английский"
- generate_image        → "Сгенерируй фото..."
- creative_writing      → "Напиши песню про..."
- follow_up             → "Еще", "Больше", "Продолжи"
- clarification         → "Уточни", "Не понял"
- opinion               → "Что думаешь о..."
- comparison            → "Сравни Python и JavaScript"
```

### 2. Извлечение сущностей

Из запроса извлекаются ключевые сущности:

```typescript
// Примеры:
"Какая погода в Москве?" → { city: "Москва" }
"Переведи Hello на русский" → { text: "Hello", targetLang: "русский" }
"Сгенерируй фото заката" → { prompt: "закат" }
"Напиши песню про любовь" → { theme: "любовь" }
```

### 3. Обновление контекста

Контекст обновляется после каждого сообщения:

```typescript
context = {
  topic: "Погода",              // Текущая тема
  lastTopic: "Программирование", // Предыдущая тема
  entities: Map {               // Извлеченные сущности
    "city" => "Москва",
    "language" => "Python"
  },
  intent: "weather",            // Текущее намерение
  sentiment: "neutral",         // Настроение
  turnCount: 15,                // Количество ходов
  conversationFlow: [...]       // Поток разговора
}
```

### 4. Генерация контекстного ответа

Если намерение неизвестно или требуется follow-up:

```typescript
// Follow-up
Пользователь: "Расскажи о Python"
J: "Python — это язык программирования..."
Пользователь: "Еще подробнее"
J: "Продолжаю тему 'Python'... Python используется в..."

// Clarification
Пользователь: "Что ты имеешь в виду?"
J: "Позвольте уточнить мой предыдущий ответ..."

// Opinion
Пользователь: "Что думаешь о квантовых компьютерах?"
J: "Как AI-ассистент, я стараюсь быть объективным..."
```

## 💬 Примеры диалогов

### Сценарий 1: Follow-up (продолжение темы)

```
Вы: Расскажи о машинном обучении

Вы: Еще подробнее
J: Продолжаю тему "Машинное обучение"...
   Машинное обучение включает:
   • Обучение с учителем
   • Обучение без учителя
   • Обучение с подкреплением
   
   [🔄 Еще подробнее] [📝 Другая тема]

Вы: Расскажи про обучение с учителем
J: Обучение с учителем (supervised learning)...
```

### Сценарий 2: Clarification (уточнение)

```
Вы: Что такое API?
J: API (Application Programming Interface)...

Вы: Не понял, можешь объяснить проще?
J: Позвольте уточнить мой предыдущий ответ...
   API — это как меню в ресторане:
   Вы заказываете блюдо (запрос),
   кухня готовит (обработка),
   и вам приносят результат (ответ).
   
   [🔄 Перефразируй] [📝 Пример]
```

### Сценарий 3: Opinion (мнение)

```
Вы: Что думаешь о Python vs JavaScript?
J: Как AI-ассистент, я стараюсь быть объективным.
   По поводу "Python vs JavaScript":
   
   Это интересная тема с разными точками зрения.
   Могу привести аргументы за и против.
   
   [🔍 Найти информацию] [⚖️ Аргументы за и против]
```

### Сценарий 4: Comparison (сравнение)

```
Вы: Сравни React и Vue
J: Для сравнения мне нужно знать, что именно вы хотите сравнить.
   
   Например:
   • "Сравни Python и JavaScript"
   • "В чем разница между React и Vue"
   • "Что лучше: SQL или NoSQL"
   
   [🐍 Python vs JS] [⚛️ React vs Vue]
```

### Сценарий 5: Контекстная память

```
Вы: Какая погода в Москве?
J: 🌤️ Погода в Москве: +15°C, облачно...

Вы: А в Санкт-Петербурге?
J: 🌤️ Погода в Санкт-Петербурге: +12°C, дождь...
   (J помнит что мы обсуждаем погоду)

Вы: А завтра?
J: 🌤️ Прогноз на завтра...
   (J помнит контекст "погода" и последний город)
```

## 🔧 Техническая реализация

### Архитектура:

```
┌─────────────────────────────────────┐
│      Пользовательский запрос        │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Context Engine                    │
│   ├─ Анализ намерения               │
│   ├─ Извлечение сущностей           │
│   ├─ Обновление контекста           │
│   └─ Анализ настроения              │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Обработчик намерений              │
│   ├─ Если известно → обработка      │
│   └─ Если неизвестно → контекст     │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Генерация ответа                  │
│   ├─ Контекстный ответ              │
│   ├─ Follow-up ответ                │
│   └─ Стандартный ответ              │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Обновление истории                │
│   ├─ Добавление в контекст          │
│   └─ Обучение на диалоге            │
└─────────────────────────────────────┘
```

### Файлы:

- `src/utils/contextEngine.ts` — движок контекста
- `src/utils/aiAgent.ts` — интеграция с AI-агентом
- `src/App.tsx` — использование в интерфейсе
