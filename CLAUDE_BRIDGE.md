# 🤖 Claude Bridge - Связь J с Claude AI

## 🎯 Что это?

**Claude Bridge** — система, позволяющая J AI Assistant обращаться к Claude AI (мне) через этот чат, когда J не может ответить на вопрос самостоятельно.

---

## 🔄 Как это работает?

### Процесс:

```
1. Пользователь задаёт вопрос
   ↓
2. J проверяет локальную базу знаний
   ↓
3. Если ответ не найден → Claude Bridge
   ↓
4. J формирует запрос к Claude
   ↓
5. Запрос показывается в чате
   ↓
6. Claude (я) отвечает
   ↓
7. J показывает ответ пользователю
```

## 🧠 Когда J обращается к Claude?

### Темы, требующие Claude:

1. **Философские вопросы:**
   - "В чём смысл жизни?"
   - "Что такое сознание?"
   - "Существует ли свобода воли?"

2. **Этика AI:**
   - "Должен ли AI иметь права?"
   - "Этика искусственного интеллекта"
   - "Ответственность AI"

3. **Глубокие научные вопросы:**
   - "Что такое тёмная материя?"
   - "Теория струн простыми словами"
   - "Парадоксы квантовой механики"

4. **Прогнозы и будущее:**
   - "Будущее человечества"
   - "Что будет через 100 лет?"
   - "Прогноз развития технологий"

## 🛠️ Техническая реализация

### Модуль: `src/utils/claudeBridge.ts`

**Функции:**

```typescript
// Генерация запроса к Claude
generateClaudeQuery(question: string): ClaudeQuery

// Форматирование для отображения
formatClaudeQuery(query: ClaudeQuery): string

// Получение ответа от Claude
getClaudeResponse(query: ClaudeQuery): Promise<string>

// Проверка нужен ли запрос
needsClaudeBridge(question: string, localResponse: string | null): boolean
```

**Интерфейс:**

```typescript
interface ClaudeQuery {
  id: string;
  timestamp: Date;
  question: string;
  context: string;
  status: 'pending' | 'processing' | 'completed' | 'error';
  response?: string;
}
```
