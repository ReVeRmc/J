# 👁️ Система компьютерного зрения J AI Assistant

## 🎯 Обзор

J AI Assistant теперь может **видеть ваш экран**, понимать контекст работы и предлагать контекстные команды для управления программами.

---

## 🚀 Возможности

### 1. Анализ экрана в реальном времени

**Команды:**
- `что на экране` - полный анализ текущего экрана
- `какая программа активна` - определение активного приложения
- `что я делаю` - распознавание текущей активности

**Что анализируется:**
- 🪟 Активное окно и приложение
- 🎯 Текущая активность пользователя
- 📝 Текст на экране (OCR)
- 🎭 Настроение/режим работы
- 💡 Контекстные подсказки

### 2. Контекстное управление программами

**Команды:**
- `помоги с этим` - подсказки для текущей программы
- `как закрыть` - помощь с текущим приложением
- `что делать` - рекомендации по контексту

**Поддерживаемые приложения:**
- 🌐 Google Chrome - серфинг, поиск, вкладки
- 💻 Visual Studio Code - программирование, отладка
- 📁 Проводник Windows - управление файлами
- 📝 Microsoft Word - документы, форматирование
- 📊 Microsoft Excel - таблицы, формулы
- 🎨 Adobe Photoshop - изображения, дизайн
- 💬 Telegram - мессенджер, чаты
- 🎵 Spotify - музыка, плейлисты

### 3. Статистика использования

**Команды:**
- `статистика использования` - анализ паттернов работы
- `что я чаще делаю` - частые активности
- `мои паттерны` - анализ поведения

**Что отслеживается:**
- 💻 Часто используемые приложения
- 🎯 Типичные активности
- 🎭 Распределение настроения
- 📈 Паттерны использования

## 🔧 Техническая реализация

### Архитектура

```
┌─────────────────────────────────────┐
│      Пользовательская команда       │
│   "что на экране" / "помоги"        │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   smartResponder.ts                 │
│   ├─ Проверка команд зрения         │
│   └─ Вызов screenAnalyzer           │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   screenAnalyzer.ts                 │
│   ├─ Захват скриншота               │
│   ├─ Определение активного окна     │
│   ├─ Распознавание приложения       │
│   ├─ OCR (распознавание текста)     │
│   ├─ Анализ UI элементов            │
│   ├─ Формирование контекста         │
│   └─ Генерация подсказок            │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│   Electron main.js                  │
│   ├─ PowerShell скрипт захвата      │
│   └─ Анализ активного процесса      │
└─────────────────────────────────────┘
```

### Основные файлы

- **`src/utils/screenAnalyzer.ts`** - анализатор экрана (350+ строк)
  - Захват скриншотов
  - Распознавание приложений
  - OCR текст
  - Анализ UI элементов
  - Формирование контекста
  - Генерация подсказок
  - Статистика использования

- **`src/utils/smartResponder.ts`** - интеграция с обработчиком
  - Команды анализа экрана
  - Контекстная помощь
  - Статистика

- **`src/App.tsx`** - UI кнопки
  - Секция "КОМПЬЮТЕРНОЕ ЗРЕНИЕ"
  - Быстрые кнопки анализа

### Профили приложений

```typescript
interface AppProfile {
  name: string;
  patterns: string[];           // Паттерны распознавания
  typicalActivities: string[];  // Типичные активности
  commands: string[];           // Доступные команды
}
```

**Пример профиля VS Code:**
```typescript
'vscode': {
  name: 'Visual Studio Code',
  patterns: ['vscode', 'visual studio', 'редактор кода', 'код'],
  typicalActivities: ['программирование', 'редактирование', 'отладка', 'git'],
  commands: ['сохрани файл', 'запусти', 'открой терминал', 'найди в файлах'],
}
```

## 🔐 Безопасность

### Приватность

- 📸 Скриншоты сохраняются во временной папке
- 🗑️ Автоматическое удаление после анализа
- 🔒 Данные не отправляются на внешние серверы
- 🏠 Вся обработка локальная

### Ограничения

- ⚠️ OCR работает в упрощённом режиме
- ⚠️ Распознавание UI элементов базовое
- ⚠️ Для полного OCR нужен Tesseract.js
- ⚠️ Анализ изображений требует дополнительных библиотек

## 🚀 Расширение функционала

### Добавление новых приложений

1. Откройте `src/utils/screenAnalyzer.ts`
2. Добавьте профиль в `APP_PROFILES`:

```typescript
'newapp': {
  name: 'New Application',
  patterns: ['newapp', 'новое приложение'],
  typicalActivities: ['активность1', 'активность2'],
  commands: ['команда1', 'команда2'],
}
```

3. Пересоберите приложение
