# 📦 Генератор исполняемых файлов J AI Assistant

## 🎯 Обзор

J AI Assistant теперь может **создавать исполняемые файлы** различных форматов: BAT, PowerShell, EXE-подобные скрипты, ZIP-архивы и многое другое.

---

## 🚀 Возможности

### Поддерживаемые форматы

**📝 BAT скрипты:**
- BAT Установщик - создание установщиков программ
- BAT Бэкап - скрипты резервного копирования
- BAT Очистка - очистка системы
- BAT Системная информация - сбор информации о ПК
- BAT Автозапуск - добавление в автозагрузку
- BAT Тест сети - диагностика сети
- Простой EXE (через BAT) - создание исполняемых BAT-файлов

**⚙️ PowerShell скрипты:**
- PowerShell Установщик - продвинутые установщики
- PowerShell Мониторинг - мониторинг системы в реальном времени

**📦 Архивы:**
- ZIP Архив - создание инструкций по архивации

## 🔧 Техническая реализация

### Архитектура

```
Пользователь → smartResponder → fileGenerator → Electron → FileSystem
                (обработка)      (генерация)      (API)      (сохранение)
```

### Основные файлы

- **`src/utils/fileGenerator.ts`** - генератор файлов (500+ строк)
  - Шаблоны файлов (10+ типов)
  - Генерация содержимого
  - Сохранение через Electron API
  - Статистика созданных файлов

- **`src/utils/smartResponder.ts`** - интеграция с обработчиком
  - Распознавание команд создания файлов
  - Вызов fileGenerator
  - Отображение результатов

- **`src/App.tsx`** - UI кнопки
  - Секция "📦 ГЕНЕРАТОР ФАЙЛОВ"
  - Быстрые кнопки создания

### Структура шаблона

```typescript
interface FileTemplate {
  id: string;                    // Уникальный ID
  name: string;                  // Название шаблона
  category: string;              // Категория (script, installer, etc.)
  extension: string;             // Расширение файла
  description: string;           // Описание
  generate: (params) => string;  // Функция генерации
  defaultParams: any;            // Параметры по умолчанию
}
```

## 🚀 Расширение функционала

### Добавление новых шаблонов

1. Откройте `src/utils/fileGenerator.ts`
2. Добавьте новый шаблон в `FILE_TEMPLATES`:

```typescript
{
  id: 'custom_template',
  name: 'Мой шаблон',
  category: 'script',
  extension: '.bat',
  description: 'Описание шаблона',
  defaultParams: { name: 'custom' },
  generate: (params) => {
    return `@echo off
echo Мой скрипт
pause`;
  },
}
```

3. Пересоберите приложение: `.\Build-Exe.ps1`

### Пример: Добавление шаблона для создания ярлыка

```typescript
{
  id: 'bat_shortcut',
  name: 'BAT Ярлык',
  category: 'script',
  extension: '.bat',
  description: 'Создаёт ярлык для программы',
  defaultParams: { name: 'shortcut', options: { target: '' } },
  generate: (params) => {
    const target = params.options?.target || 'notepad.exe';
    return `@echo off
set SCRIPT="%TEMP%\%RANDOM%.VBS"
echo Set oWS = WScript.CreateObject("WScript.Shell") >> %SCRIPT%
echo sLinkFile = oWS.SpecialFolders("Desktop") \\ "${params.name}.lnk" >> %SCRIPT%
echo Set oLink = oWS.CreateShortcut(sLinkFile) >> %SCRIPT%
echo oLink.TargetPath = "${target}" >> %SCRIPT%
echo oLink.Save >> %SCRIPT%
cscript /nologo %SCRIPT%
del %SCRIPT%
echo Ярлык создан!
pause`;
  },
}
```
